# Music-player-application
College Term project
Programmer: Daniel Santillanes
Goal: Sit idly in the background of a user's mobile device, reading and playing MP4 files while allowing for the user to skip, go back, pause, play, and close the application from a pull down tab.
Uses: Allows for users to utilize music files transferred from their computers or other sites and play them back without the need of a subscription plan, streaming service, or a secondary device without the need for constant Wi-Fi connection.
Users are free to look over the code and download it as needed to test, configure , and consider all possible applications of this app while also interacting with other builds made by programmers who've done the same. 
I will maintain and contribute to the main project for the Music player while balancing free customizability and ease of use to edit the script as necessary. 

Road Map
|Now|
-Local storage permissions and MP3 file scanning & recognition
-Basic Audio playback system (Play, Pause, skip, go back, seek, etc.)
-Folder(or metadata) based track list 

|Next|
-Custom Playlist building system( allow for creation, editing, deleting of song queues)
-Appearance customization (basic dark and light mode themes with the intent to add personal themes for users)
-Multi-language support

|Later|
-Lock screen & notification Media control
-Extended audio format support
-Open source compatibility
-Desktop compatibility
